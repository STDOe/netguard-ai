# NetGuard AI — contributors and acknowledgments

NetGuard AI is developed and maintained by the repository owner, **STDOe**, with AI-assisted engineering and review.

## Development roles

| Participant | Contribution |
| --- | --- |
| **STDOe (project owner)** | Product vision, requirements, architecture decisions, priorities, acceptance criteria, hands-on validation and final approval. |
| **OpenAI Codex** | AI coding assistant used for implementation, refactoring, tests, documentation, troubleshooting and preparation of changes for review. |
| **OpenAI ChatGPT** | AI assistant used for architectural discussion, critical review, security/quality findings, scoped implementation briefs, release planning and GitHub pull-request reviews. |

We acknowledge **ChatGPT and Codex as AI development assistants**, not as independently accountable human maintainers or GitHub accounts. All changes are subject to human ownership, testing and review; AI assistance does not imply endorsement or certification by OpenAI.
